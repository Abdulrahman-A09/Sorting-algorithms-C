# Sorting-algorithms-C
Which sorting algorithm is fastest under varying conditions, and what data characteristics make comparison-based vs. non-comparison-based algorithms perform best? 

** Step 1: Choose programing language. I chose C and I will stick to it for the entire project. 

Step 2: Build a program for each of the algorithms I’ll pick for this experiment. 

Step 3: Write a program that generates lists of random numbers at different sizes (or take data that needs sorting in real life situations). I’ll try to find an expert to go through each algorithm and program I will be writing for fairness. 

Step 4: Make a program that runs a timer and the algorithm at approximately the same time, then subtract the time difference between when the timer started and the algorithm. 

Step 5: Repeat for accuracy and take the average (each algorithm can be ran millions of times in seconds so I will decide the number of repeats later). 

Step 6: Compare the results. Which algorithm is the fastest in each size? How much slower each algorithm gets as the list grows. Where do non-comparison algorithms win? Note the algorithms limitations. As well as noting memory and resource usage (how much work the computer has to do). 

Step 7: Conclusion.
